# SHIMER — Librería/Papelería (e-commerce) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Entregar el sitio de SHIMER completo y desplegado — catálogo navegable desde Supabase, carrito, checkout que persiste la orden, panel `/admin` protegido, todo online en Vercel + Render.

**Architecture:** Monorepo npm-workspaces con 3 piezas: `apps/web` (Next.js 15 App Router → Vercel), `apps/api` (Express 5 → Render), `supabase/` (migraciones SQL + seed, aplicadas por MCP). El navegador nunca ve la `service_role`: toda escritura pasa por la API. El carrito vive en el cliente y se revalida contra la API en el checkout.

**Tech Stack:** Next.js 15 · React 19 · Tailwind CSS v4 · `motion` · `gsap` + `ScrollTrigger` · `lenis` · `@supabase/supabase-js` · `@supabase/ssr` · Express 5 · `helmet` · `cors` · `express-rate-limit` · `zod` · `jose` · Vitest · supertest · Testing Library · Playwright.

**Spec:** `docs/superpowers/specs/2026-10-07-shimer-design.md`

## Global Constraints

Copiado literal del spec; aplica a **todas** las tareas salvo que la tarea diga lo contrario.

- **Tokens de color** (únicos; no se agregan más): `violet #7C3AED`, `magenta #E935C1`, `pink #FF6B9D`, `cream #FDF9F3` (fondo de página, nunca blanco puro), `ink #17111F`, `mint #00B2AC` (éxito / disponible).
- **Fuentes:** `Fredoka` (display) + `Plus Jakarta Sans` (texto), vía `next/font`. Cero peticiones a Google en runtime.
- **Degradado de marca** `--gradiente-marca: linear-gradient(135deg, violet, magenta, pink)`: solo logo, precios y hero. Nunca en bloques de texto largos.
- **Dinero:** todo importe es entero, nunca float. Convención `*_bob_cents integer`, **1 Bs = 100**. `Bs. 8.50` → `850`; `Bs. 549` → `54900`. Formato de salida: `Bs. 549.00`, miles con `,` y decimal con `.` (igual que WooCommerce: `price_decimals: 2`, `decimal_separator: '.'`).
- **Convención de oferta:** `precio_bob_cents` es el precio **de lista**; `precio_oferta_bob_cents` es el precio **en oferta** y siempre es menor (o `null`). "Bs. 549 (antes 595)" ⇒ lista `595`, oferta `549`. El precio efectivo es `precio_oferta_bob_cents ?? precio_bob_cents`.
- **El total se calcula en el servidor**, nunca se acepta del cliente. `nombre_snapshot` y `precio_unitario_bob_cents` quedan congelados en la fila del pedido.
- **Folios:** prefijo `SHM-` + 6 dígitos con ceros a la izquierda (`SHM-000001`), generados por la función SQL `next_folio()` (atómica).
- **Error único en toda la API:** `{"error": {"code": string, "message": string, "details": []}}`.
- **404 en vez de 403** en todo lo que negue acceso, para no confirmar existencia de recursos.
- **Zod valida en el borde** de toda entrada. Queries parametrizadas (`.eq()`, `.gte()`), nunca SQL concatenado.
- **Rate limit:** 20 req/min general · 5 req/min en `POST /api/orders`.
- **El navegador nunca recibe `service_role`.** Vive solo en Render.
- **Animación:** solo `transform` y `opacity`. Nunca `width/height/top/left`, nunca animar `scroll` (lo hace Lenis). Reveal = `opacity 0→1` + `translateY 24px→0`, `0.7s`, `power3.out`. Hover `scale 1.03`, `200–300ms`. Grillas `stagger 0.06s`. `prefers-reduced-motion: reduce` → sin animación.
- **Server Components por defecto** en Next; `'use client'` solo donde hay interacción.
- **Identificadores:** repo `miloh0690-gif/Shimer` · servicio Render `shimer-api` · producto "SHIMER" · `<title>` y footer legal "SHIMER — Librería, Papelería y Arte" · team Vercel `team_jsYNMLk0Eox6x0SLZBmk6SyH` · workspace Render `tea-dagf9grl550s73bfh1hg` · org Supabase `qzvbxmcoordjkceunqoo`.
- **Datos demo:** todos los productos seedeados llevan `demo = true` y se borran con `delete from products where demo = true`.

## Review Focus

Cinco clases de entrada/fallo que el spec implica pero que ninguna tarea cubre sola. Cada línea tiene su test fijado en la tarea indicada.

1. **Producto en oferta se cobra al precio de lista.** Cualquier lugar que muestre o cobre un precio debe usar `precio_oferta_bob_cents` cuando existe. → `precioEfectivo` en Task 4 (API), `ProductCard` en Task 10 (lista tachada + efectivo visible), y el checkout real en Task 12 Step 4.
2. **Doble clic en "Finalizar".** La misma `idempotency-key` reenviada devuelve el mismo folio y no crea una segunda orden, incluso con dos requests concurrentes. → Task 5 (`creado === false`, `createCount === 1`, y el caso de la unique violation).
3. **`localStorage` manipulado.** Precio 0, cantidad negativa o `product_id` inexistente no cambian el total: el servidor decide. Cantidad ≤ 0 se rechaza con 400. → Task 5 (`resolveLines` ignora el precio del cliente, rechaza 0/negativa y 404) + Task 8 (el reducer nunca deja cantidad ≤ 0) + Task 12 Step 4 punto 2.
4. **Imagen de producto ausente o URL rota.** Se renderiza `placeholder.svg`, nunca el ícono de imagen rota del navegador. → `ImagenProducto` en Task 10 + `home.spec.ts` "ninguna imagen rota" en Task 15.
5. **Stock 0.** El producto aparece en el catálogo pero no se puede agregar, y si se fuerza el pedido la API responde `409 STOCK_INSUFICIENTE`. → Task 4/5 (409) + `ProductCard` y `AddToCartButton` en Tasks 10 y 11.

```sql
create table brands (
  id uuid primary key default gen_random_uuid(),
  slug text unique not null,
  nombre text not null,
  logo_url text,
  created_at timestamptz not null default now()
);
create table categories (
  id uuid primary key default gen_random_uuid(),
  slug text unique not null,
  nombre text not null,
  descripcion text,
  orden int not null default 0
);
create table products (
  id uuid primary key default gen_random_uuid(),
  slug text unique not null,
  nombre text not null,
  descripcion text,
  brand_id uuid references brands(id) on delete set null,
  category_id uuid references categories(id) on delete set null,
  precio_bob_cents integer not null check (precio_bob_cents >= 0),
  precio_oferta_bob_cents integer,
  stock integer not null default 0 check (stock >= 0),
  sku text, color text, imagenes text[] not null default '{}',
  destacado boolean not null default false,
  demo boolean not null default true,
  activo boolean not null default true,
  created_at timestamptz not null default now(),
  updated_at timestamptz not null default now(),
  constraint oferta_menor check (precio_oferta_bob_cents is null or precio_oferta_bob_cents < precio_bob_cents)
);
create table product_variants (
  id uuid primary key default gen_random_uuid(),
  product_id uuid not null references products(id) on delete cascade,
  nombre text not null, valor text not null,
  stock integer not null default 0 check (stock >= 0),
  sku text, orden int not null default 0
);
create table counters (nombre text primary key, valor bigint not null default 0);
create or replace function public.next_folio() returns text
language plpgsql as $$
declare v bigint;
begin
  insert into counters (nombre, valor) values ('folio', 1)
  on conflict (nombre) do update set valor = counters.valor + 1
  returning valor into v;
  return 'SHM-' || lpad(v::text, 6, '0');
end $$;
create table orders (
  id uuid primary key default gen_random_uuid(),
  folio text unique not null,
  idempotency_key text unique not null,
  cliente_nombre text not null,
  cliente_email text not null,
  cliente_telefono text not null,
  envio_tipo text not null check (envio_tipo in ('cochabamba','nacional')),
  envio_direccion text, envio_ciudad text,
  estado text not null default 'nuevo'
    check (estado in ('nuevo','confirmado','preparando','enviado','entregado','cancelado')),
  total_bob_cents integer not null check (total_bob_cents >= 0),
  created_at timestamptz not null default now()
);
create table order_items (
  id uuid primary key default gen_random_uuid(),
  order_id uuid not null references orders(id) on delete cascade,
  product_id uuid references products(id) on delete set null,
  nombre_snapshot text not null,
  precio_unitario_bob_cents integer not null,
  cantidad integer not null check (cantidad > 0),
  subtotal_bob_cents integer not null
);
create table profiles (
  id uuid primary key references auth.users(id) on delete cascade,
  email text, nombre text,
  rol text not null default 'cliente' check (rol in ('cliente','admin')),
  created_at timestamptz not null default now()
);
create index products_activo_idx on products (activo) where activo;
create index products_category_idx on products (category_id);
create index products_brand_idx on products (brand_id);
create index orders_email_idx on orders (cliente_email);
```

import { createServerClient } from '@supabase/ssr';
import { cookies } from 'next/headers';

export async function getSupabaseServer() {
  const cookieStore = await cookies();
  return createServerClient(
    process.env.NEXT_PUBLIC_SUPABASE_URL!,
    process.env.NEXT_PUBLIC_SUPABASE_ANON_KEY!,
    { cookies: { getAll: () => cookieStore.getAll(), setAll: (list) => list.forEach(({ name, value, options }) => cookieStore.set(name, value, options)) } },
  );
}
